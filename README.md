# 월간 물가 브리핑 (Money Newsletter)

매달 한국의 최신 **소비자물가**와 **생산자물가**를 공식 통계 API에서 받아와서, 경제를 잘 모르는 사람도 읽기 쉬운 **HTML 이메일 뉴스레터**로 만들어 보내는 자동화 프로젝트입니다.

<p align="center"><img src="price-briefing/docs/email-preview.png" width="360" alt="뉴스레터 메일 미리보기"></p>

## 주요 기능

- **소비자물가 상승률**: 전년동월대비 %와 전월 대비 변화(↑/↓, %p)
- **근원물가**: 농산물 및 석유류 제외 지수, 식료품 및 에너지 제외 지수
- **물가 흐름 판단**: 물가상승률과 근원물가를 2% 기준으로 비교해 세 단계로 분류
  - 둘 다 2% 이상 → 📈 물가가 계속 오르는 흐름
  - 물가상승률만 2% 이상 → 〰️ 잠깐 출렁인 것으로 보임
  - 물가상승률 2% 미만 → ✅ 물가 안정권
- **주요 등락품목**: 약 460개 품목 중 물가에 미친 영향(지수 변화 × 가중치)이 큰 상승 12개, 하락 8개를 골라 부문별 표로 정리 (상승은 빨간색, 하락은 파란색)
- **부문별 물가**: 농축수산물, 공업제품, 석유류, 서비스, 외식 등 특수분류 지수의 등락률
- **생산자물가 전망**: 생산자물가 등락률로 1~3개월 뒤 소비자물가 압력을 판단
- **모바일 대응 HTML 메일**: 표 기반 레이아웃과 인라인 스타일로 메일 앱에서도 깨지지 않게 작성
- **원문 수치만 사용**: 값을 찾지 못하면 추정하지 않고 "확인 불가"로 표시

## 시스템 구조

```
 ┌──────────────┐   매월 3~7일 14:00 (KST)
 │  스케줄러     │ ───────────────────────────┐
 └──────────────┘                             ▼
                               ┌──────────────────────────┐
                               │ 1. 이번 달 발송 여부 확인   │──── 이미 보냄 → 종료
                               └──────────────────────────┘
                                              ▼
 ┌──────────────────┐  HTTPS   ┌──────────────────────────┐
 │ 한국은행 ECOS API │ ◀─────── │ 2. fetch_ecos.py         │──── 지난달 통계 미발표 → 종료
 └──────────────────┘          │    CPI·PPI 지수 수집      │     (다음 날 재시도)
                               └──────────────────────────┘
                                              ▼ data.json
                               ┌──────────────────────────┐
                               │ 3. build.py              │◀── sectors.json
                               │    등락률 계산·판단 규칙   │    (품목 → 부문 분류)
                               │    HTML 메일 생성         │
                               └──────────────────────────┘
                                              ▼ email.html, summary.json
                               ┌──────────────────────────┐
                               │ 4. Gmail로 발송           │
                               └──────────────────────────┘
```

현재는 Claude의 예약 작업이 스케줄러 역할을 하고, 발송 여부 확인과 메일 발송은 Gmail 커넥터로 처리합니다. 수치 계산은 모두 파이썬 스크립트가 API 값으로만 합니다.

### 왜 보도자료가 아닌 API인가

처음에는 국가데이터처와 한국은행 보도자료 게시판을 읽으려 했지만, 해외 클라우드 서버에서는 게시판 목록이 비어 있는 상태로 응답했습니다. 그래서 같은 공식 통계를 제공하는 **한국은행 경제통계시스템(ECOS) Open API**로 바꿨습니다. 소비자물가는 국가데이터처가 작성한 통계를 ECOS가 제공하는 것이라 수치의 출처는 같습니다. 다만 보도자료와 반올림 방식이 달라 0.1%p 정도 차이가 날 수 있습니다.

## 데이터 출처

| 항목 | 작성 기관 | ECOS 통계표 |
|---|---|---|
| 소비자물가지수 (품목별) | 국가데이터처 | `901Y009` |
| 소비자물가지수 (특수분류: 근원물가, 부문별) | 국가데이터처 | `901Y010` |
| 생산자물가지수 (총지수) | 한국은행 | `404Y014` |

## 파일 구성

```
price-briefing/
├── fetch_ecos.py          # ECOS API에서 최근 월 CPI·PPI 데이터 수집 → data.json
├── build.py               # 등락률 계산, 판단 규칙 적용, HTML 메일 생성
├── sectors_2026-10.json   # 2026년 10월 선정 품목의 부문 분류 예시
├── email_2026-10.html     # 2026년 10월 발송 메일 예시
└── docs/
    └── email-preview.png  # README용 메일 미리보기
```

## 실행 방법

Python 3.9 이상, 표준 라이브러리만 사용합니다.

```bash
cd price-briefing

# 1. 데이터 수집 (키를 생략하면 ECOS 체험용 키 'sample'로 조회, 호출당 10건 제한이라 2~3분 걸림)
python3 fetch_ecos.py [ECOS_API_KEY] > data.json

# 2. 선정 품목 목록 만들기 (부문 분류 파일 없이 한 번 실행하면 out/items.json 생성)
python3 build.py data.json none.json out

# 3. out/items.json을 보고 품목별 부문을 sectors.json에 적은 뒤 다시 실행
python3 build.py data.json sectors.json out
# → out/email.html, out/summary.json (메일 제목 포함)
```

ECOS 정식 인증키는 [ECOS Open API](https://ecos.bok.or.kr/api/)에서 무료로 발급받을 수 있습니다.
